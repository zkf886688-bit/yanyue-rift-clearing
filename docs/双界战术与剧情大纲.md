# 回响归途：路线与结尾

主线仍是短局射击，剧情不打断每轮战斗。

货运前庭 → 折光长廊 → 十字研究所 → 燃料转运港 → 南侧核心大厅。
长廊北侧 → 回响工坊（可选救援、随机锻造）→ 东侧折返通道 → 研究所。

工坊有一名未归维修员。按E稳定回响后，他会自行沿修复的回程锚点回站，不需要护送AI或跟随寻路。奖励仅领取一次：6金币与补满护盾。

Boss清除后，不再只显示战绩。第一幕拒绝第八次重启：救回的人不该再次失去明天。第二幕根据救援状态回应绕路行为；未救援时保留坐标，已救援时显示归站人物。第三幕回到归航灯前，零问明天是否会更好，衍月回答“一起修好它”。主题是选择承担未来，以及愿意为别人停下。

尾声三页，E/Enter/Space或按钮继续，最后进入结算。射击与移动在尾声中停止。下一局救援状态重置，不假称永久养成。

双界战术：蓝界压制裂隙体、红界破蓝盾；命中蓄共鸣，满能量切换短时爆发。Boss核心颜色指示当前更有效的世界。
