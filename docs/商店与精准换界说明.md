# 商店与精准换界

- 前庭南门清场后开放，沿通道绕向东侧进入补给室，中央柜台E。
- 转运港东门清场后开放，向东进入血契室，中央档案员E；南门仍通向Boss。
- 血药8金币/2生命，电池7金币/2护盾，相位蓄电器16金币/蓄能提高25%。
- 追光血契：1生命上限换精准反击+2枚；双界连携：2生命上限换切换后1.2秒新子弹伤害+22%；铸命筹码：1生命上限换20金币。
- 血契最少保留3生命上限；价格影响本局，残血不回血，不跨局继承。
- 精准换界：预计0.2秒内即将命中的敌弹，或即将照到玩家且未被掩体阻断的激光预警，按Tab成功可反击并获得26共鸣。判定冷却5秒，普通换界仍可清弹。
- Boss跃起先标出激光方向，落地接光束和扩散弹；持续直线后退更容易被组合攻击压住，可以横向闪避或临危精准换界。
