# 归航剧情与引导

主线因果：第七次重启让红蓝时间线重叠，坍缩守卫以闭源型协议封存唯一答案，也封住了求救信号。衍月每清理一个战区，恢复一段回程锚点，将归航灯接向核心。击败守卫后保留失能现场，再跟随回响进入主题尾声。

## 入站接引

首次入站8步高亮：任务 → 移动、鼠标攻击、Space闪避、E交互、Esc暂停 → 武器架选开局枪 → 红蓝靶试射与Tab → 同色实体/异色虚化 → 任务终端目标与记录 → 调度员剧情和建议 → 传送出发。

介绍后接实际操作练习；介绍与练习都允许跳过、重看，不锁住出击。任务终端展示目标和记录，调度员解释事故、归航计划和战术，两者分工保留。

## 首次战斗

暂停刷怪和计时，按HUD位置逐一介绍血量护盾、武器、Tab、共鸣、Space、目标与地图、金币成长、敌人预警。左上红心/青条明确标注生命/护盾，说明伤害先扣护盾。

介绍包括：蓝界移速与蓄能更快、红界贯穿破盾、满100共鸣Tab触发2.8秒爆发并回复1护盾、基础换界3秒/精准判定5秒、闪避1.6秒、金币补给、随机锻造、血契最低保留3生命上限、普通木箱无掉落、危险桶伤害双方。更详细敌人规则放在可展开手册内。

完成初次介绍有准备时间；重试不强制重复。暂停菜单可重看，结束回暂停，不额外改变战斗资源。

## 跨区衔接

- 前庭清空：第一锚点恢复，获得备用枪，说明Q与东侧主路、南侧补给。
- 长廊进入：收到北侧工坊求救，主路仍可先走。
- 工坊：外勤工匠说明东南角维修员与随机锻造。
- 研究所：已救援时回应维修员回站与新坐标；未救援时保留求救坐标。
- 研究所清空：说明备用枪与转运港方向。
- 转运港：能源环恢复，指向东侧血契和南侧核心。
- 核心：坍缩守卫/闭源型出场、三阶段战斗、现场失能、主动继续、交叉淡入归航尾声。

所有介绍都用游戏里的真实位置和HUD高亮，未用静态截图代替可玩的流程。
