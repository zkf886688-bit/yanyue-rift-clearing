# 参赛辨识度与演示方案

建议主张：一次换界，改变空间与弹幕的归属。视觉符号用破裂双月、青粉相位轮廓与归航灯保持一致。

按用户提供的评审截图，创意20%、玩法25%、完成度25%，三项合计70%。演示优先让评委亲眼看到机制和反馈，剧情与视听服务同一个主题。评分仍取决于现场体验与具体评审，无法保证获奖。

30秒核心演示：先让敌弹被青色实体墙挡住；换到红界穿过同一面虚影，原路或掩体发生变化；再在来弹将命中时精准换界，圆点与短光条按原形状返还，击中敌人。讲清“Tab改变空间，也改变攻击归属”。

后续短演示：武器架比较三把枪，进入有主支路的地图；工坊救援及血契体现局内取舍；Boss闭源型守卫试图保留唯一答案，玩家通过不同世界打开其他走法；失能现场与归航灯尾声回应救援主题。

最值得继续真人试玩的点：两色轮廓是否一眼能读懂、实体化拒绝切换提示是否及时、回响返还有无成功感、首次6步引导是否过长。以这四个具体体验调整，不以新增系统数量代替趣味性。
